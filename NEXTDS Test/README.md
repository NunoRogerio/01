# NEXTDS Test

The NEXT Design System Table, as working code.

- `Table.jsx`: the source. The `DataTable` component plus the test screen around it (Configuration, Exploration and the VSP 360 sample data).
- `index.html`: the same code in a page that runs in the browser. React 18.3.1 and Babel load from cdnjs, and the JSX compiles when the page opens.

Theme colours come from the NEXT library v6.3.2.1 (Dawn and Wicked).
